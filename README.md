## Rock Paper Scissors Game

A modern, responsive web-based implementation of the classic Rock Paper Scissors game. This project features a "battle-style" interface designed for a smooth user experience across different screen sizes.

## Live Demo
[Check out the live game here!](https://Dishajindal10.github.io/rock-paper-scissor_Game/)

##Features
- **Responsive Design:** Utilizes CSS Flexbox and Viewport units (`vh`/`vw`) for a perfect 2-column split layout.
- **Interactive UI:** Custom button animations and hover effects using CSS transitions.
- **Clean Codebase:** Organized project structure with separate concerns for HTML, CSS, and JavaScript.
- **User-Centric Layout:** "Player vs Computer" battle positions inspired by modern gaming interfaces.

## Tech Stack
- **HTML5:** Semantic structure.
- **CSS3:** Flexbox layout, custom animations, and responsive styling.
- **JavaScript (ES6):** DOM manipulation and game logic (under development).
